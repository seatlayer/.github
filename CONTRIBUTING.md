# Contributing

Thanks for helping improve SeatLayer's SDKs, examples and integrations.

- **Bugs and feature requests:** open an issue in the repository for the package
  you are using. Include the package version, platform, and the smallest steps
  that reproduce the problem.
- **Questions about using SeatLayer:** start with the documentation at
  https://docs.seatlayer.io/. For account or billing questions, email
  hello@seatlayer.io.
- **Security issues:** never open a public issue. Follow [SECURITY.md](SECURITY.md).
- **Pull requests:** keep each one to a single change, describe what it fixes
  and how you tested it, and run the repository's own checks before opening it.
  For a larger change, open an issue first so the approach can be agreed.

Never commit secret keys, customer data or live event keys, including in tests
and screenshots.
